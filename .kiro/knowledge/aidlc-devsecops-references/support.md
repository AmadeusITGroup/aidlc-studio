# SDL Support & Tickets (on-demand reference)

> **On-demand reference for the devsecops agent.** When the user hits a scanner
> or SDL tooling issue, surface the matching support link. The agent does **not**
> create tickets itself (there is no ServiceNow integration) — it presents the
> correct pre-filled ServiceNow catalog link for the user to open in a browser.
